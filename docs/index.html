为什么它很强大？
🎧

一个 App 听遍三大平台

网易云 / QQ 音乐 / 酷狗音乐一键切换，每日推荐、排行榜、歌单广场、搜索、热门搜索全部跟随平台。

🔐

多平台账号登录

网易云扫码 / 网页登录、QQ 扫码 / 网页授权、酷狗账号登录，同步歌单、收藏、听歌排行与 VIP / SVIP 标识。

🎨

封面即主题

动态封面取色，背景渐变、进度条、按钮、歌词高亮全部实时跟随专辑封面主色。

💬

专业级歌词定制

逐行跟随、点击跳转、翻译、自定义颜色 / 渐变 / 发光 / 模糊、3D 立体倾斜、长按多选复制。

🖼️

液态玻璃界面

iOS 26 原生 Liquid Glass 材质，深浅色自适应，App Store 风格底栏，抖音式滑动切歌。

🎛️

全自由度定制

5 套全局主题、自定义壁纸库、全局主题色、底部布局自由拖动、设置一键备份恢复。

⚡

播放能力拉满

多档音质（标准~Hi-Res）、免费听歌开关、歌曲下载、锁屏控制、后台播放、队列、倍速、睡眠定时。

📊

数据全同步

听歌排行、播放历史、歌单云端同步，登录后一切都在。
